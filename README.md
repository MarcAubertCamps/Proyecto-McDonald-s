# Proyecto McDonald's

Skills personales para Claude Code.

## Skills

- **grill-me** (`.claude/skills/grill-me/SKILL.md`): te interroga a fondo sobre un plan, decisión o idea, en rondas de preguntas numeradas con una respuesta recomendada para cada una, hasta llegar a un entendimiento compartido. Se activa al pedir "grill me" o similar.

## Uso

Clona este repo y abre Claude Code dentro: las skills en `.claude/skills/` se cargan automáticamente. Para tenerlas en todos tus proyectos, copia la carpeta de la skill a `~/.claude/skills/`.

Basada en [mattpocock/skills](https://github.com/mattpocock/skills) (licencia MIT).
